# 🧬 Bio Quiz Summarizer

A lightweight web application that turns PDF study notes into an interactive quiz to help memorize key concepts quickly.

## ✨ Technologies

* HTML

## 🚀 Features

* **Interactive Quizzes:** Tests knowledge from PDF summaries with immediate feedback.
* **Score Tracking:** Automatically tallies the number of questions you get right and wrong.
* **One-Line Reviews:** Displays a concise, single-line note related to each question so you can remember topics at a glance.
* **No Server Required:** Runs directly entirely in the browser.

## 📍 The Process

I built this project to manage my study timeline and make catching up on lectures more efficient. Reading PDFs can be passive, so I wanted a tool that forces active recall. The main focus was keeping the interface simple so users can instantly jump between testing themselves and reviewing the single-line summaries to remember everything about a topic instantly. 

## 🚦 Running the Project

1. Clone this repository to your local machine.
2. Open the `index.html` file in your preferred web browser.
3. Start the quiz!
